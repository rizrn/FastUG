# FastUG

FastUG is a Python tool for technical writers who publish several variants of a user guide for the same product.
- Write the guides once in short Markdown commands
- Reuse shared sections across variants and FastUG expands them into a finished guide
- Preview and Export to PDF with VS Code and Markdown Preview Enhanced.

## Requirements

- Python 3 (standard library only)
- VS Code with the Markdown Preview Enhanced extension
- Optional: PyMuPDF (`pip install pymupdf`) for page numbers in the table of contents

## Getting started

python script/script.py 1

For full instructions, see the user guide: [FastUG-Guide.md](FastUG-Guide.md).
